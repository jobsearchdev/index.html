Потрібен fine-grained token з доступом лише до репозиторію сайту і дозволом Contents: Read and write. Без галочки token зберігається лише до закриття вкладки.

Що редагувати

Додавайте, змінюйте, переставляйте й видаляйте пункти. Кожне поле має українську та англійську версію.

Для досвідчених: сирий HTML секцій. Некоректний HTML може зламати сторінку. Новий текст тут не перекладається автоматично.
