# Резюме-сайт

Сайт: https://jobsearchdev.github.io/index.html/
Редактор: https://jobsearchdev.github.io/index.html/editor.html

## Як редагувати сайт

1. Відкрий редактор і встав GitHub token (див. нижче). Постав галочку «Запам’ятати token», щоб не вводити його щоразу.
2. Натисни «Підключитися та завантажити».
3. Вибери, що редагувати:
   - **Списки** — досвід роботи, проєкти, сертифікати, навички, фокус, лабораторії, навчання, освіта. Тут можна додавати, змінювати, переставляти (↑ ↓) і видаляти пункти. Кожне поле має версію UA і EN. До сертифіката можна завантажити картинку (JPG/PNG/WEBP).
   - **Тексти** — заголовки, абзаци, кнопки, назва вкладки. Ліворуч українська, праворуч англійська. Є пошук.
   - **Контакти** — email, LinkedIn, GitHub. Оновлюються в усіх місцях сторінки.
   - **HTML** — для досвідчених: сирий HTML секцій.
4. Натисни «Перегляд UA» або «Перегляд EN», щоб побачити результат до публікації.
5. Натисни «Опублікувати на GitHub». Сайт оновиться за 1–2 хвилини (Cmd+Shift+R). Дата «Інформацію оновлено» на сайті ставиться автоматично.

Якщо щось пішло не так до публікації — «Скасувати всі незбережені зміни». Після публікації будь-яку версію можна повернути в історії репозиторію на GitHub.

## Як створити GitHub token

github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token:
- Repository access: Only select repositories → `index.html`
- Permissions → Contents: Read and write

Коли token закінчиться, створи новий так само.

## Структура файлів

- `index.html` — сторінка (українські тексти за замовчуванням).
- `locales/uk.json`, `locales/en.json` — тексти обох мов. Ключ = значення атрибута `data-i18n` на сторінці.
- `site-lists.js` — шаблони списків для редактора.
- `certificates/` — картинки й PDF сертифікатів.
- `editor.html`, `editor.js`, `editor.css` — редактор.

## Перегляд на своєму комп’ютері

```bash
cd ~/Documents/GitHub/site/index.html
python3 -m http.server 8000
```

Відкрий http://localhost:8000 (сайт) або http://localhost:8000/editor.html → «Завантажити локальні файли».
